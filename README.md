# Aldo Jason - Personal Portfolio

Welcome to my personal portfolio repository! This project showcases my finalized software projects, technical skills, education, and ways to contact me. Built using modern **HTML5, Vanilla CSS3, and JavaScript**, the website is fully responsive, interactive, and visually engaging with a dark glassmorphic design and smooth micro-animations.

🔗 **Live Site:** [https://aldojason.github.io/portfolio](https://aldojason.github.io/portfolio)

## 🚀 Key Features

- **Responsive Design**: Flawless experience across mobile, tablet, and desktop screens.
- **Glassmorphic Aesthetic**: Deep galaxy dark mode with glowing accents, subtle borders, and smooth transitions.
- **Interactive Skills Section**: Categorized filter tabs (Frontend & Mobile, Backend & Databases, AI & ML, DevOps & Tools) with visual level tags.
- **Finalized Projects Showcase**: Featured cards with tech stack badges, key feature checklists, and source/demo links.
- **Project Filtering**: Instant category filtering (AI & Machine Learning, Full-Stack & Web, Mobile & Automation).
- **Working Contact Section**: Integrated contact form and verified social links.
